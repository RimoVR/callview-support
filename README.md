# Callview support

Callview is a read-only CT review client for authorized CHILI WebViewer users.

This public repository contains support and privacy information only. It does
not contain the Callview source code, credentials, patient information, study
identifiers, or gateway data.

## Support

- For installation or access questions, open a [support issue](https://github.com/RimoVR/callview-support/issues).
- Do not include patient information, screenshots with identifiers, passwords,
  CHILI URLs, or other confidential data in an issue.
- You can also contact the developer at [pmk@pmn.de](mailto:pmk@pmn.de).

## Privacy

Read the [Callview privacy policy](privacy-policy.md).

Callview does not bundle patient data. Live studies are loaded only after the
user signs in to an authorized CHILI service and remain session-bound.
